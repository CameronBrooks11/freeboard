# Security Policy

## Reporting a Vulnerability

Do not report security issues in public GitHub issues.

Use GitHub private vulnerability reporting:

- https://github.com/CameronBrooks11/freeboard/security/advisories/new

Include:

1. A concise summary and impacted component(s).
2. Reproduction details and prerequisites.
3. Severity/impact assessment.
4. Suggested remediation (if available).

## Response Expectations

1. Initial acknowledgement target: within 3 business days.
2. Triage and severity assignment after acknowledgement.
3. Fix timeline depends on severity and exploitability.

## Disclosure Policy

1. Please allow time for triage and remediation before public disclosure.
2. Once fixed, coordinated disclosure details can be shared in advisory/release notes.
